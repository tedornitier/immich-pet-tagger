Reference photo analysis

Scores every reference photo by how much it actually contributes to the classifier, so you can prune dead weight and catch bad crops. It uses whichever reference and negative photos are set up on the main enrollment page (edit refs there and re-run here to see the effect). Nothing is changed — this is read-only diagnostics. A run embeds each ref and, for each one, retrains the model without it (leave-one-out); ref sets are small so this is quick.

Redundancy — how similar this ref's embedding is to the pet's other refs (cosine, 0–100%). High means a near-duplicate carrying little new information.
Self — the model's confidence for the pet on this ref's crop when it was held out of training. Low means the other refs don't explain it: a genuinely informative hard case, or a bad crop.
Influence — the log-odds shift in the pet's other refs when this one is removed. Positive = load-bearing (removing it hurts); near zero = contributes little; negative = removing it helps, i.e. it's pulling the boundary the wrong way (likely a bad or mislabeled ref). On a clean, well-separated set every ref lands close to zero — that's expected; watch for the outliers, especially negative ones.

Reference photos

“Not a pet” photos

The same idea for your negative samples. Here a high held-out score is what makes a negative valuable: it means the model would mistake it for a pet, so keeping it teaches the classifier to reject that look-alike. Negatives that are trivially “not a pet” anchor the class but do little discriminating work, and near-duplicate negatives are wasted slots.

Pet-likeness — how strongly the model takes this photo for a pet when it's held out of training (and which pet). High = a hard negative doing real work rejecting false positives; low = easy filler. The small number after “most like N” is the raw cosine similarity of this photo to that pet's reference photos — a model-free “how close does it look”, separate from the classifier's own score.
Redundancy — cosine similarity to the most similar other negative. High means a near-duplicate you could drop.
